Arduino-Based Remote Control and Distance Warning System

Built on Arduino UNO with MPU6500 gyroscope, HC-SR04 ultrasonic sensor, and SG90 servo. MPU6500 enables tilt-based servo control; HC-SR04 triggers autonomous obstacle avoidance. Bare-metal programming — a first step from embedded control toward embodied intelligence.

A fork of Harmonic-HN by Simon Halvdansson, adding on-device translation via Google ML Kit. Supports 50 languages, bilingual and overlay display modes, all running offline for privacy. Working toward graceful auto-translation and LLM-based translation API support.
